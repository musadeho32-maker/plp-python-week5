# Week 5 Assignment: Password Generator & Your Own Module

## Project Files

- `password_generator.py`: Generates random passwords using Python's random and string modules.
- `helpers.py`: Contains functions for calculating the number of tables needed and welcoming users.
- `main.py`: Imports the helpers module and uses its functions.

## What I Learned

I learned how to use Python's built-in modules and create my own module. I also practised using functions, default parameters, imports, and the `if __name__ == "__main__":` condition.
